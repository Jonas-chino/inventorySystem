# Development Environment

To develop this software, I used **Visual Studio Code** as my primary code editor, along with the integrated **Git Bash** terminal. I utilized the **.NET CLI** (`dotnet` commands)

The project is written entirely in **C#** utilizing the **.NET SDK**. It relies on the following core native libraries:

- `System`: For basic console input/output and primitive data type parsing (`int.Parse`).
- `System.Collections.Generic`: For managing dynamic data structures, specifically `List<T>`.
- `System.Linq`: For advanced data querying and object filtering (utilizing the `FirstOrDefault` method).
- `System.IO`: For persistent data storage, reading, and writing to external text files (`StreamWriter` and `File.ReadAllLines`).
